# The Gen Academy onboarding

A responsive, dependency-free onboarding hub built from The Gen Academy brand guidelines and the Mastering Agentic AI Week 3 project brief.

## Run locally

```bash
npm run dev
```

Then open [http://localhost:4173](http://localhost:4173).

## Structure

- `index.html`: onboarding, course map, technical interview workspace, and marketing placeholder
- `styles.css`: responsive TGA design system and page layouts
- `app.js`: navigation, progress persistence, course accordions, and project detail interactions

Onboarding checklist progress is stored only in the current browser through `localStorage`.
